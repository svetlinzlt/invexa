# Как да стигнем до работещо приложение без Mac

Имаш Windows и iPhone. Това е достатъчно, за да стигнеш до приложение на
телефона си — но пътят е различен и си струва да го знаеш точно.

---

## Какво не може

**Компилиране от Windows.** Кодът за iOS се превежда с iOS SDK, който Apple
разпространява само заедно с Xcode, само за macOS. Няма кросплатформен
компилатор, няма емулатор, няма легална виртуална машина на чужд хардуер.

**Инсталиране направо на iPhone от компютъра.** iPhone приема само подписани
пакети, а подписването минава през инструменти на Apple.

**Swift Playgrounds** прави приложения направо на устройство — но само на
**iPad**, не на iPhone.

---

## Какво може, и то безплатно

**Чужд Mac, който сам компилира вместо теб.**

GitHub дава изпълнители с macOS без пари за публични хранилища. Сглобяването
за симулатор **не иска нито подпис, нито платен акаунт**. Значи целият код
може да мине през истински компилатор още днес, без да купуваш нищо.

Файлът `.github/workflows/ios.yml` е готов. Прави две неща:

1. Пуска 87-те теста на логиката.
2. Сглобява цялото приложение и изкарва всяка грешка в лога.

### Как се пуска

```bash
git init && git add . && git commit -m "Invexa"
```

Създай **публично** хранилище в GitHub и:

```bash
git remote add origin https://github.com/ПОТРЕБИТЕЛ/invexa.git && git push -u origin main
```

Отваряш раздела **Actions** в GitHub и гледаш. При грешка отваряш стъпката
„Само грешките" — там са първите шейсет реда с `error:`.

**Дай ми ги и ги оправям.** Цикълът е: пращаш промените, чакаш около пет
минути, четем грешките, поправям, пращаш пак. Бавно е спрямо Xcode, но е
безплатно и работи изцяло от Windows.

> Хранилището трябва да е **публично** за безплатни macOS изпълнители. Ако
> това не ти е удобно, частните струват около 0,08 USD/минута — 15–20 USD, за
> да минем през поправките.

## После: на телефона ти

След като кодът се компилира, има два пътя до iPhone-а.

### Път 1 — TestFlight през CI · 99 USD/год.

Никога не докосваш Mac. Изпълнителят подписва и качва, ти инсталираш през
TestFlight.

Нужно е:

- [ ] Apple Developer Program — **99 USD/год.**
- [ ] Сертификат за разпространение. Заявката се прави с OpenSSL **на Windows**:
      `openssl req -new -newkey rsa:2048 -nodes -keyout ios.key -out ios.csr`
      Качваш `.csr` в портала, сваляш `.cer`, сглобяваш `.p12` с OpenSSL.
- [ ] Provisioning profile за App Store — прави се в портала, без Mac.
- [ ] Сертификатът и профилът се слагат като секрети в GitHub.
- [ ] Работният поток се разширява с подпис и `xcrun altool` за качване.

Реално е, но е фиданка работа за настройване и **всяка промяна струва
20–30 минути** до телефона: сглобяване, обработка в TestFlight, инсталиране.
За стабилно приложение е добре. За гонене на грешки при компилация е мъчение.

### Път 2 — Mac под наем за няколко дни · 10–30 €

Точно за фазата, в която сме. Свързваш се от Windows и работиш в Xcode с
всичките му удобства: грешките излизат веднага, симулаторът тръгва за
секунди, поправяш и пробваш пак.

| Доставчик | Цена | Как се свързваш |
|---|---|---|
| Scaleway Apple Silicon | ~0,10 €/час | VNC от Windows |
| MacinCloud | ~1 USD/час, пакети | RDP от Windows |
| MacStadium | месечно, по-скъпо | VNC |

Двайсет часа работа са около **10–20 €**. Това е по-евтино от една вечеря и
сваля най-голямото неизвестно в целия проект.

---

## Какво бих направил на твое място

**Днес, безплатно:** качваш кода в GitHub и пускаш работния поток. Разбираш
дали логиката минава и колко грешки има в интерфейса. Нула лева.

**След това:** ако грешките са малко, довършваме ги през CI. Ако са много —
Mac под наем за два-три дни е по-евтин от времето, което ще изгубиш в цикли
по пет минути.

**Едва накрая:** 99 USD за Developer Program и TestFlight, когато има какво да
се инсталира. Дотогава не са нужни.

> Купуването на Mac остава най-доброто решение, ако проектът продължи след
> валидацията. Но не е нужно **сега**, за да разберем дали кодът работи — и
> точно това е следващият въпрос, на който трябва да си отговорим.
