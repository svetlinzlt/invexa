# Invexa

Месецо-центрично приложение за лични финанси за европейски потребители на
iPhone. Отговаря на един въпрос: **къде отидоха парите този месец.**

В момента е между фаза 0 и фаза 1 — кодът е написан, но още не е компилиран.

## Устройство

```
ios/
├── InvexaCore/      Логиката като отделен пакет — 87 теста, без симулатор
├── Invexa/          Приложението: SwiftUI, SwiftData, CloudKit
├── InvexaWidgets/   Начален и заключен екран
└── project.yml      Проектът като текст; .xcodeproj се поражда с XcodeGen

web/                 Целевата страница на Next.js, /bg и /en
```

---

## Бърз старт

**Логиката** — не иска Mac, ако имаш Swift; иначе го прави CI автоматично:

```bash
swift test --package-path ios/InvexaCore
```

**Целевата страница** — работи на Windows:

```bash
npm install --prefix web && npm run dev --prefix web
```

**Приложението** — виж [`ios/NO-MAC.md`](ios/NO-MAC.md). Накратко: качваш в
публично хранилище в GitHub и работният поток `.github/workflows/ios.yml`
компилира всичко на безплатен macOS изпълнител.
